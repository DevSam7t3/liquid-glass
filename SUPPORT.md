# Support

Thank you for using `@avenra/liquid-glass`! This document provides information on how to get support and where to find answers to your questions.

## Documentation

Before seeking support, please check our official documentation:

- [Getting Started Guide](https://docs.avenra.online/docs/liquid-glass/getting-started)
- [API Reference](README.md#api-reference)

## Community Support

If you have a question or need help with using the library, please use the following channels:

### GitHub Discussions

The best place to ask questions, share ideas, and interact with the community is our [GitHub Discussions](https://github.com/DevSam7t3/liquid-glass/discussions) page.

### GitHub Issues

If you have found a bug or want to suggest a new feature, please open an [Issue](https://github.com/DevSam7t3/liquid-glass/issues).

- Use the **Bug Report** template for bugs.
- Use the **Feature Request** template for new ideas.

**Note:** Please do not use GitHub Issues for general support questions.

## Security Vulnerabilities

If you discover a security vulnerability, please do not report it publicly. See our [Security Policy](SECURITY.md) for instructions on how to report it responsibly.

## Professional Support

Currently, this is a community-driven open-source project. We do not offer official paid professional support at this time.
